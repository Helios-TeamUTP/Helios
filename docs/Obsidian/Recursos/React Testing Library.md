## De Qué Se Trata

Documentación oficial: https://testing-library.com/docs/react-testing-library/intro

Librería para probar componentes de React simulando interacción real del usuario (render, queries por rol/texto, eventos), en lugar de probar detalles de implementación.

---

## Cómo lo Uso en HELIOS

Se usa junto con [[Vitest Docs]] para las pruebas funcionales del frontend — por ejemplo, los componentes del flujo de agendamiento (`SelectorSede.tsx`, `SelectorEspecialidad.tsx`, `SelectorMedico.tsx`, `SelectorHorario.tsx`, `ConfirmacionCita.tsx`) construidos en el [[Módulo 01 — Agendamiento de Citas]].
