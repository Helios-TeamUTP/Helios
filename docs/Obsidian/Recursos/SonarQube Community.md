## De Qué Se Trata

Producto: https://www.sonarsource.com/products/sonarqube

Análisis estático de código — detecta code smells, vulnerabilidades, duplicación y mide cobertura de pruebas. La edición Community ya está configurada en el pipeline de HELIOS (ver [[Proyecto - HELIOS]] → Tareas Completadas).

## Cómo lo Uso en HELIOS

- Corre sobre el código producido cada semana (ver tareas pendientes en [[Daily — Semana 2 — Sprint 1]]: "Correr SonarQube sobre el código producido")
- Las métricas de SonarQube alimentan el reporte ISTQB de calidad del proyecto
- Complementa al [[Reporte de Bugs — Sprint 1 y 2]] — SonarQube encuentra problemas estructurales, la auditoría manual encuentra bugs funcionales
