## Cómo lo Uso en HELIOS

- El repositorio [[GitHub — Helios]] está conectado a Railway — cada push a las ramas configuradas dispara un nuevo deploy
- Railway sirve el frontend de React + TypeScript ya compilado
- Objetivo del proyecto: los 4 módulos funcionales deben quedar desplegados aquí (ver [[Proyecto - HELIOS]] → Objetivo Principal)
