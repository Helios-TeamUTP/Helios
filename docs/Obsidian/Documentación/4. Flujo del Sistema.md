## 4.1 Introducción

Este documento describe los flujos completos del sistema HELIOS organizados por actor (paciente, médico, administrador) y por módulo. Incluye los diagramas de flujo generados para los 4 módulos del Parcial 1 y el flujo general de cada rol de usuario.

Los diagramas de flujo de los módulos se encuentran en la carpeta `docs/` del repositorio GitHub y en la carpeta `Diseño/` de este vault de Obsidian.

---

## 4.2 Actores del Sistema

|Actor|Prioridad|Descripción|
|---|---|---|
|Paciente|ALTA|Ciudadano que agenda, cancela y gestiona sus citas|
|Médico|ALTA|Profesional que gestiona su agenda y atiende pacientes|
|Administrador|BAJA|Personal administrativo que monitorea el sistema|
|Sistema|ALTA|Procesos automáticos: cron, notificaciones, sincronización|

## 4.4 Flujo del Paciente

### 4.4.1 Acceso y Registro

```
[Página Principal — HELIOS]
        │
        ├── ¿Tiene cuenta?
        │       │
        │    [SÍ] → Inicio de Sesión
        │    │         │ Correo o cédula + contraseña
        │    │         │ Máx. 5 intentos → bloqueo 15 min
        │    │         │ Doble factor (opcional)
        │    │         ▼
        │    │    [Dashboard Paciente]
        │    │
        │    [NO] → Registro
        │              │ Nombre completo
        │              │ Cédula panameña / pasaporte
        │              │ Fecha de nacimiento, sexo
        │              │ Teléfono, correo
        │              │ Contraseña
        │              │ Tipo de cobertura:
        │              │   → Asegurado CSS
        │              │   → Beneficiario MINSA
        │              │   → Seguro privado
        │              │   → Pago particular
        │              │ Aceptar políticas
        │              ▼
        │         Verificación por correo o SMS
        │              ▼
        │         [Cuenta activa]
        │              ▼
        │         [Dashboard Paciente]
        │
        [Recuperar contraseña] → Link por correo → Nueva clave
```

### 4.4.2 Dashboard del Paciente

```
[Dashboard Paciente]
        │
        ├── Próximas citas (lista)
        ├── Notificaciones importantes
        ├── Acceso rápido:
        │     ├── Agendar Cita → [Módulo 01]
        │     ├── Mis Citas → [Módulo 02]
        │     ├── Notificaciones → [Módulo 04]
        │     ├── Directorio Médico
        │     ├── Resultados médicos (visión futura)
        │     └── Mi Perfil
```

### 4.4.3 Descubrimiento de Servicios

```
[Directorio de Policlínicas]
        │
        ├── Filtrar por provincia:
        │     Panamá · Colón · Chiriquí · Veraguas
        │     Coclé · Herrera · Los Santos · Darién
        │     Bocas del Toro · Panamá Oeste
        │
        ├── Por cada sede ver:
        │     Dirección · Horario · Especialidades · Mapa
        │
        └── Seleccionar sede → [Flujo Agendamiento]

[Directorio Médico]
        │
        ├── Filtrar por especialidad:
        │     Medicina General · Pediatría · Cardiología
        │     Dermatología · Ginecología · Odontología
        │
        ├── Por cada médico ver:
        │     Nombre · Especialidad · Disponibilidad
        │
        └── Seleccionar médico → [Flujo Agendamiento]
```

### 4.4.4 Gestión de Expediente (Visión Futura)

```
[Expediente Médico Digital]
        │
        ├── Historial clínico
        │     Consultas previas · Diagnósticos
        │     Tratamientos · Medicamentos recetados
        │
        ├── Resultados médicos
        │     Laboratorios · Radiografías
        │     Resonancias · Documentos descargables
        │
        └── Recetas digitales
              Medicamentos · Indicaciones · Vigencia
```

### 4.4.5 Seguridad del Paciente

```
[Protección de Datos]
        │
        ├── Historial cifrado (AES-256 via Supabase)
        ├── Sesión expira a las 8h de inactividad
        ├── Cierre automático
        ├── Historial de dispositivos conectados
        └── Alertas de acceso sospechoso
```

### 4.5.3 Gestión de Agenda Médica

```
[Configuración de Horarios]
        │

### 4.5.4 Atención Médica (Consulta)

```
[Inicio de Consulta]
        │
        ├── Verificar identidad del paciente
        ├── Abrir expediente clínico
        └── Visualizar:
              Historial médico · Alergias
              Medicamentos activos · Consultas previas

[Durante la Consulta]
        │
        ├── Registrar motivo de consulta
        ├── Registrar signos vitales
        ├── Diagnóstico preliminar
        └── Observaciones médicas

[Diagnóstico y Tratamiento]
        │

        ├── Emitir prescripción médica digital
        ├── Indicaciones de tratamiento

              Laboratorios · Referencias médicas

[Finalización]

        ├── Guardar expediente

### Módulo 01 — Agendamiento de Citas

> Diagrama: [[Pantallas — Módulo 01]]

```
[Paciente Login]
        │
        ▼
[Seleccionar Sede]
        │
        ▼
[Seleccionar Especialidad]
        │
        ▼
[Sistema consulta médicos disponibles — Supabase]
        │
        ▼
[Seleccionar Médico]
        │
        ▼
[Verificación de disponibilidad en tiempo real]
        │
        ├── [Disponible] ──────────────────┐
        │                                  ▼
        └── [No disponible] → Mostrar    [Seleccionar Fecha y Hora]
              otro horario                  │
                                           ▼
                                    [Confirmar datos]
                                    Sede · Médico · Fecha
                                    Cobertura · Canal notif.
                                           │
                                           ▼
                                    [Sistema registra en Supabase]
                                           │
                            ┌─────────────┼─────────────┐
                            ▼             ▼             ▼
                     [Sync con      [Confirmación  [Notificación
                      sedes]         al paciente]   al médico]
```

**Tipos de prueba:** Funcional · Rendimiento · Usabilidad **Criterio clave:** Respuesta < 2s · SUS ≥ 75 · Sync < 5s

### Módulo 03 — Sincronización entre Sedes

> Diagrama: [[Pantallas — Módulo 03]]

```
[Evento generado — INSERT/UPDATE/DELETE en citas]
        │
        ▼
[Supabase Realtime detecta cambio]
        │
        ▼
[Propagar cambio a todas las sedes via canal citas-sync]
        │
        ▼
[Confirmar recepción por cada sede]
        │
        ├── [ÉXITO] → Log sync exitoso → Fin
        │
        └── [FALLO]
               │
               ▼
        [Reintento 1 — espera 1s]
               │
               ├── [ÉXITO] → Log intentos=1 → Fin
               └── [FALLO]
                      │
                      ▼
               [Reintento 2 — espera 2s]
                      │
                      ├── [ÉXITO] → Log intentos=2 → Fin
                      └── [FALLO]
                             │
                             ▼
                      [Reintento 3 — espera 4s]
                             │
                             ├── [ÉXITO] → Log intentos=3 → Fin
                             └── [FALLO CRÍTICO]
                                    │
                                    ▼
                             [Log estado=fallido]
                                    │
                                    ▼
                             [Alerta al Admin]
```

**Tipos de prueba:** Integración · Rendimiento · Seguridad **Criterio clave:** 99% sync < 3s · 0 datos personales en logs

## 4.8 Flujo de Seguridad Transversal

Este flujo aplica a todos los módulos y todos los actores:

```
[Request del cliente]
        │
        ▼
[¿Tiene JWT token válido?]
        │
        ├── [NO] → Redirigir a login → Fin
        │
        └── [SÍ]
               │
               ▼
        [¿Rol autorizado para esta operación?]
               │
               ├── [NO] → Error 403 → Fin
               │
               └── [SÍ]
                      │
                      ▼
               [RLS aplica filtros adicionales]
                      │
                      ▼
               [Solo ve sus propios datos]
                      │
                      ▼
               [Respuesta al cliente via HTTPS]
```
