# Flujo del Paciente - HELIOS Panamá

## 1. Acceso y Bienvenida

### Página Principal
- Presentación del sistema HELIOS Panamá
- Información de policlínicas afiliadas
- Acceso rápido a:
  - Agendar cita
  - Consultar resultados
  - Directorio médico
- Botón de iniciar sesión
- Registro de nuevos pacientes

### Registro de Paciente
- Ingreso de datos personales
  - Nombre completo
  - Cédula panameña o pasaporte
  - Fecha de nacimiento
  - Sexo
  - Número telefónico
  - Correo electrónico
- Verificación mediante:
  - SMS
  - Correo electrónico
- Creación de contraseña
- Aceptación de políticas y consentimiento médico

### Inicio de Sesión
- Correo o número de cédula
- Contraseña
- Recuperación de contraseña
- Validación en dos pasos (opcional)

## 3. Gestión de Citas Médicas

### Agendar Cita
- Selección de policlínica
- Selección de especialidad
- Selección del médico
- Consulta de horarios disponibles
- Selección de:
  - Fecha
  - Hora
- Confirmación de datos
- Generación de comprobante digital

### Métodos de Pago
- Asegurado CSS (verificación por cédula, gratis)
- Beneficiario MINSA (atención gratuita o $1-5)
- Pago particular en clínica (efectivo o tarjeta)

### Confirmación de Cita
- Resumen completo
- Código de cita
- Descarga de comprobante PDF
- Envío por:
  - Correo electrónico
  - SMS
